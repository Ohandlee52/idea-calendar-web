# 아이디어 캘린더 — 모바일 웹앱

폰에서도 메모를 쓰고 볼 수 있는 웹앱입니다. PC 앱(Electron)과 같은 계산 로직(`logic.js`, `holidays.js`)을 함께 씁니다.

---

## 🚀 처음 한 번만 하는 준비 (약 5분)

### 1단계. Supabase에 표 만들기

1. [supabase.com](https://supabase.com) 로그인 → 프로젝트 선택 (없으면 **New project**로 새로 만들기)
2. 왼쪽 메뉴 **SQL Editor** → **New query**
3. 이 폴더의 **`supabase-setup.sql`** 내용을 통째로 붙여넣고 **Run**
4. "Success. No rows returned" 이 나오면 완료

### 2단계. 연결 정보 확인

Supabase 대시보드 → **Settings → API** 에서 두 가지를 복사합니다.

| 항목 | 예시 | 설명 |
|---|---|---|
| **Project URL** | `https://abcdefgh.supabase.co` | 내 프로젝트 주소 |
| **anon public** (또는 publishable) | `eyJhbGci...` / `sb_publishable_...` | 공개돼도 안전한 키 |

> ⚠️ **secret / service_role 키는 절대 쓰지 마세요.** 유출되면 남이 내 데이터를 통째로 읽고 지울 수 있습니다.
> 실제 보호는 `supabase-setup.sql`이 켠 보안 규칙(RLS)이 담당합니다 — **내 메모는 나만** 보입니다.

### 3단계. 앱에 입력

앱을 열면 **⚙️ 연결 설정** 화면이 나옵니다. 위 두 값을 붙여넣고 **저장하고 시작**을 누르세요.
(이 정보는 그 기기에만 저장되며, 나중에 메뉴 ☰ → *연결 설정 바꾸기* 로 변경할 수 있습니다.)

### 4단계. 계정 만들기

첫 화면에서 이메일·비밀번호(6자 이상)를 넣고 **계정 만들기**를 누릅니다.
가입 확인 메일이 오면 링크를 누른 뒤 로그인하세요.
**PC와 폰에서 같은 계정으로 로그인하면 메모가 공유됩니다.**

## 📱 폰 홈 화면에 설치하기

- **안드로이드(크롬)**: 주소창 옆 ⋮ → **앱 설치** 또는 **홈 화면에 추가**
- **아이폰(사파리)**: 아래 공유 버튼 → **홈 화면에 추가**

설치하면 일반 앱처럼 아이콘으로 실행되고 주소창이 사라집니다.

---

## 🖥️ 내 컴퓨터에서 시험해 보기

```bash
node serve.js
```

브라우저에서 `http://localhost:8123` 접속.

## 📁 파일 설명

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `app.css` | 디자인 (모바일 우선) |
| `app.js` | 동작 (로그인·달력·메모·알림·동기화) |
| `logic.js` | 검색·정렬·날짜 계산 (PC 앱과 공유) |
| `holidays.js` | 한국 공휴일 표 (PC 앱과 공유) |
| `config.js` | 연결 설정 기본값 (보통 비워둠 — 앱에서 직접 입력) |
| `manifest.json`, `sw.js`, `icon-*.png` | 홈 화면 설치(PWA)용 |
| `supabase-setup.sql` | Supabase 준비 SQL (한 번 실행) |
| `serve.js` | 내 컴퓨터 시험용 작은 서버 |

## ✅ 되는 기능 / ⏳ 아직 안 되는 기능

**되는 것**: 달력·공휴일, 날짜별 메모 작성·수정·삭제, 자동 저장, 통합 검색,
고정 메모 상시 표시, 여러 개 알림(날짜·시간), 링크 열기, 모아보기, 홈 화면 설치

**아직 안 되는 것** (PC 앱에만 있음): 이미지 OCR 스캔, 글자 꾸미기(굵게·색),
이미지 첨부, `.ics` 캘린더 가져오기/내보내기, 파일 백업·복원

**PC 앱과의 메모 공유**는 아직 연결 전입니다 (다음 단계).
현재 PC 앱은 구글드라이브 JSON, 웹앱은 Supabase를 씁니다.
