# AI 분석 서버 함수 — 배포 방법

폰 앱의 **🤖 AI 분석** 단추는 이 서버 함수(`analyze-idea`)를 부릅니다.
서버 함수가 배포되어 있지 않으면 단추를 눌렀을 때 "서버에 연결하지 못했어요"가 뜹니다.

한 번만 하면 됩니다. 순서대로 따라 하세요.

## 0. 준비물

| | 어디서 | 비고 |
|---|---|---|
| Anthropic API 열쇠 | https://console.anthropic.com → API Keys → Create Key | `sk-ant-...` 로 시작. **비밀입니다.** 카톡·메일로 보내지 마세요 |
| 충전 | 같은 사이트 → Billing | 최소 5달러. 분석 1회에 약 50~150원 |

## 1. 표 만들기 (SQL)

Supabase → **SQL Editor** → New query → `supabase-migration-9-ai-analyses.sql` 내용을 붙여넣고 **Run**.
"Success. No rows returned" 이 나오면 됩니다.

## 2. 서버 함수 올리기

1. Supabase → 왼쪽 메뉴 **Edge Functions** → **Deploy a new function** → **Via Editor**
2. 이름(Function name)에 `analyze-idea` 라고 적습니다 (정확히 이 이름이어야 합니다)
3. 편집칸의 내용을 모두 지우고, `index.ts` 파일 내용을 통째로 붙여넣습니다
4. **Deploy** (10~30초)

## 3. 열쇠 등록

1. **Edge Functions** → **Secrets** (또는 Settings → Edge Functions → Secrets)
2. **Add new secret** → Key: `ANTHROPIC_API_KEY` / Value: 0번에서 받은 열쇠 → Save

`SUPABASE_URL`, `SUPABASE_ANON_KEY` 는 Supabase 가 알아서 넣어 주므로 등록할 필요 없습니다.

## 4. 확인

폰 앱에서 메모를 하나 열고 **🤖 AI 분석** → 확인 → 30초~1분 뒤 결과가 메모 아래에 나타납니다.

문제가 생기면 화면에 원인이 그대로 뜹니다.

| 화면에 뜨는 말 | 뜻 |
|---|---|
| 서버에 연결하지 못했어요 | 2번(함수 배포)이 안 됐거나 인터넷이 없음 |
| 서버에 AI 열쇠가 등록되지 않았습니다 | 3번(Secrets)이 안 됨 |
| AI 열쇠가 잘못됐습니다 | 열쇠를 잘못 붙여넣음. Secrets 에서 다시 등록 |
| AI 사용 잔액이 부족합니다 | Anthropic 콘솔에서 충전 |
| 하루 10번까지만 | 한 사람당 하루 10번 제한 (비용 보호). `index.ts` 의 `DAILY_LIMIT` |
| 분석 결과를 불러오지 못했어요 / 칸이 안 보임 | 1번(SQL) 미실행일 수 있음 |

## 비용 지켜보기

Anthropic 콘솔 → **Usage** 에서 실제 청구액을 볼 수 있습니다.
앱에 표시되는 "약 ○○원"은 어림값입니다 (토큰 수 × 단가, 환율 1,400원 가정).

## 고치고 싶을 때

`index.ts` 를 고친 뒤 2번을 다시 하면 됩니다 (같은 이름으로 Deploy 하면 덮어씁니다).

| 바꾸고 싶은 것 | 어디 |
|---|---|
| 하루 횟수 | `DAILY_LIMIT` |
| 웹 검색 횟수 | `MAX_WEB_SEARCHES` |
| 분석 항목·말투 | `SYSTEM_PROMPT` |
| AI 모델 | `MODEL` |
