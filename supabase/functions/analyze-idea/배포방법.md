# AI 분석 서버 함수 — 배포 방법

폰 앱의 **🤖 AI 분석**(메모 하나)과 **🤖 이 기간 AI 총평**(모아보기) 단추는 이 서버 함수(`analyze-idea`)를 부릅니다.
서버 함수가 배포되어 있지 않으면 단추를 눌렀을 때 "서버에 연결하지 못했어요"가 뜹니다.

## 0. 준비물 (한 번만)

| | 어디서 | 비고 |
|---|---|---|
| Anthropic API 열쇠 | https://console.anthropic.com → API Keys → Create Key (만료: 안 함) | `sk-ant-...` 로 시작. **비밀입니다.** 카톡·메일로 보내지 마세요 |
| 충전 | 같은 사이트 → Billing | 최소 5달러. 메모 분석 1회 약 120~200원, 기간 총평 1회 약 50~150원 (실측 기준) |

## 1. 표 만들기 (SQL) — 두 개, 순서대로

Supabase → **SQL Editor** → New query → 파일 **내용**을 붙여넣고 **Run**. "Success. No rows returned" 이 나오면 됩니다.

| 순서 | 파일 | 무엇 |
|---|---|---|
| 9번 | `supabase-migration-9-ai-analyses.sql` | 분석 결과 표 |
| 10번 | `supabase-migration-10-period-analyses.sql` | 기간 총평도 저장할 수 있게 칸 추가 |

10번을 안 돌려도 기간 총평은 **동작은** 합니다. 다만 저장이 안 되어 다시 볼 때 또 돈이 들고, 결과 아래에 "SQL 10번을 실행하면 저장됩니다"라고 뜹니다.

## 2. 서버 함수 올리기

처음: Supabase → **Edge Functions** → **Deploy a new function** → **Via Editor** → 코드 칸 전체 지우기 → `index.ts` 내용 붙여넣기 → 오른쪽 아래 이름 칸에 `analyze-idea` → **Deploy function**

고칠 때: **Edge Functions** → **analyze-idea** → **Code** 탭 → 전체 지우기 → 새 `index.ts` 내용 붙여넣기 → **Deploy**

그리고 **Settings** 탭에서 **"Verify JWT with legacy secret"** 을 **끄고 Save** (한 번만). 함수 안에서 직접 로그인을 확인합니다.

## 3. 열쇠 등록 (한 번만)

**Edge Functions** → **Secrets** → Name `ANTHROPIC_API_KEY` / Value 열쇠 → **Save**

`SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEYS` 등은 Supabase 가 알아서 넣어 줍니다.

## 4. 확인

- 메모 하나: 메모 열고 **🤖 AI 분석** → 30초~1분 뒤 결과 (8개 항목, "이미 있는 것"에 실제 제품 2~3개, "예전 아이디어와의 연관"에 내 다른 메모)
- 기간: ☰ → 모아보기 → 기간 고르기 → **🤖 이 기간 AI 총평** → 30초~1분 뒤 결과 (반복 주제, 밀고 갈 것, 보류할 것)

| 화면에 뜨는 말 | 뜻 |
|---|---|
| 서버에 연결하지 못했어요 | 2번(함수 배포)이 안 됐거나 인터넷이 없음 |
| 서버에 AI 열쇠가 등록되지 않았습니다 | 3번(Secrets)이 안 됨 |
| AI 열쇠가 잘못됐습니다 | 열쇠를 잘못 붙여넣음. Secrets 에서 다시 등록 |
| AI 사용 잔액이 부족합니다 | Anthropic 콘솔에서 충전 |
| 하루 10번까지만 | 한 사람당 하루 10번 제한 (메모 분석 + 기간 총평 합산). `index.ts` 의 `DAILY_LIMIT` |
| 서버가 시간 안에 끝내지 못했어요 | Supabase 무료 등급 함수 시간 한도 150초 초과. 기간 총평이면 기간을 줄여서 |
| SQL 10번을 실행하면 저장됩니다 | 1번의 10번 SQL 미실행 |

## 비용 지켜보기

Anthropic 콘솔 → **Usage** 에서 실제 청구액을 볼 수 있습니다.
앱에 표시되는 "약 ○○원"은 어림값입니다 (토큰 수 × 단가, 환율 1,400원 가정).

## 고치고 싶을 때

`index.ts` 를 고친 뒤 2번을 다시 하면 됩니다.

| 바꾸고 싶은 것 | 어디 | 주의 |
|---|---|---|
| 하루 횟수 | `DAILY_LIMIT` | |
| 웹 검색 횟수 | `MAX_WEB_SEARCHES` | 4번 이상은 시간 한도(150초)에 걸린 적 있음 |
| 생각 깊이·답 길이 | `EFFORT`, `MAX_TOKENS` | `high` 는 시간 한도에 걸린 적 있음 |
| 분석 항목·말투 | `MEMO_PROMPT`, `PERIOD_PROMPT`, `STYLE_RULES` | |
| AI 모델 | `MODEL` | 절약형 Sonnet 5. `claude-opus-5` 는 1회 약 650원 |
| 기간 총평에 넣는 메모 수 | `PERIOD_LIMIT`, `PERIOD_BODY_CHARS` | 많을수록 비용·시간 증가 |
